# BRIDGE: From Packet Semantics to Flow-Level Representations through Burst-Centered Behavioral Modeling

## Datasets

We use the TLS120 and VPN-App benchmark data released with Zhao et al.'s paper, *The Sweet Danger of Sugar: Debunking Representation Learning for Encrypted Traffic Classification* (ACM SIGCOMM 2025). The data are available on [Hugging Face](https://huggingface.co/datasets/rigcor7/Debunk_Traffic_Representation). For the original benchmark and preprocessing details, see the [paper](https://doi.org/10.1145/3718958.3750498) and its [official repository](https://github.com/SmartData-Polito/Debunk_Traffic_Representation).
